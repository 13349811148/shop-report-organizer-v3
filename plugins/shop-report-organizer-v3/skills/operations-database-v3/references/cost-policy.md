# 成本政策规则

## 成本来源优先级

```text
有效且档位已确认的到位价
  > 月返后结算价（个）
  > ERP成本价（仅在前两者均缺失时暂时兜底）
```

ERP成本价始终与月返价比较，但差异提醒不会自动改变成本来源。

## 有效政策判断

一条到位价同时满足以下条件才可采用：

- 商品编码、物料编码或条码精确匹配。
- 成本归属日期位于生效日和失效日之间。
- 产品级例外优先于品牌级周期政策。
- 采购档位、目标达成率或其他条件已经确认。
- 同一优先级不存在价格冲突。

月度预兑现但周期末需要统算的政策，应保存 `暂估` 状态；周期结算后新增最终版本和调整差额，不覆盖历史。

## 提醒规则

| 条件 | 成本 | 提醒 | 是否阻断 |
|---|---|---|---|
| 有有效到位价 | 到位价 | 正常－取到位价 | 否 |
| 无到位价、月返价有效 | 月返价 | 正常－取月返价 | 否 |
| 有正返点政策但到位价空白 | 月返价 | 提醒－有政策但到位价未填，暂取月返价 | 否 |
| ERP与月返价差额大于0.01元 | 仍按前述优先级 | 待确认－ERP与月返价不一致 | 否，但需人工确认来源差异 |
| 多档位未确认 | 月返价 | 待确认－存在多个政策档位但尚未确认适用档位 | 否 |
| 同级政策冲突 | 不自动选择到位价 | 待确认－同一日期存在冲突的到位价政策 | 是 |
| 三种成本都缺失 | 空白 | 待确认－到位价、月返价和ERP成本价均缺失 | 是 |

返点为0%的政策不触发“政策应填未填”提醒。

## 政策记录字段

至少保存：`政策ID、商品编码、条码、品牌、政策类型、生效日、失效日、条件类型、档位、返点率、到位价、暂估/结算状态、来源文件、来源页码、被替代政策ID`。
